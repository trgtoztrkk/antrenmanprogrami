# Sayfam

Netlify üzerinde yayınlanan tek sayfalık statik bir HTML sitesi. Telefondan (Safari) her zaman erişilebilir ve "Ana Ekrana Ekle" ile uygulama gibi açılabilir.

## Teknolojiler
- Saf HTML + CSS (derleme adımı yok)
- Netlify (statik barındırma)

## İçeriği değiştirme
`index.html` dosyasını düzenleyin. Değişiklik yayınlandığında aynı adres güncel içeriği gösterir.

## Yerelde çalıştırma
`index.html` dosyasını tarayıcıda açmanız yeterlidir. Netlify özellikleriyle birlikte denemek için: `netlify dev --port 8889`.
